```

SCRCTL   F DCBA98  543210
18009AH  □□■■■■■■□□■■■■■■
           ││││││  │││││└── N0VCSC vertical cell scroll enable
           ││││││  ││││└─── N0LSCX line scroll enable (for horizontal screen scroll value)
           ││││││  │││└─── N0LSCY line scroll enable (for vertical screen scroll value)
           ││││││  ││└────── N0LZMX line zoom enable
           ││││││  └┴───── N0LSS1,0 line scroll interval
           ││││││ 
           │││││└────────── N1VCSC vertical cell scroll enable
           ││││└─────────── N1LSCX line scroll enable (for horizontal screen scroll value)
           │││└──────────── N1LSCY line scroll enable (for vertical screen scroll value)
           ││└────────────── N1LZMX line zoom enable
           └┴────────────── N1LSS1,0 line scroll interval
```
