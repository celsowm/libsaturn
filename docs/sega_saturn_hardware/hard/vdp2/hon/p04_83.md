### ●Normal scroll screen map register : The normal scroll screen map register specifies the start address of the pattern name table for each plane when displaying the normal scroll screen in cell format. This is a 16-bit write-only register located at addresses 180040H to 18004EH. The value is cleared to 0 after power-on or reset, so be sure to set it.
