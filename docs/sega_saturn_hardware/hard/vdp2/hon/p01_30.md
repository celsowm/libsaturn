### ●Line screen : The line color screen is a screen for performing color calculations with other screens. You can make the entire screen a solid color or specify a color for each line, but you cannot display characters. The back screen is the screen that appears when all other screens are transparent. You can make the entire screen a solid color or specify a color for each line, but you cannot display characters.

### ●Window : For the normal window, you can choose between a normal rectangular window, which is specified by two screen coordinates at the top left and bottom right, and a normal line window, where the left and right screen coordinates are specified for each line. A sprite window is a window containing sprite characters. Depending on the purpose of use, the window has a ``transparency processing window'' that specifies areas to be made transparent, a ``color calculation window'' that specifies areas that will not perform color calculations, and a ``rotation parameter window'' that allows you to switch screens using two rotation parameters. There are 3 types: The windows to be used for each screen and how they are stacked can be specified for each screen.
