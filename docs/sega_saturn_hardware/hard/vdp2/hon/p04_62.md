### ●Pattern name control register : The pattern name control register specifies pattern name data size, character number auxiliary mode, and pattern name auxiliary data. This is a 16-bit write-only register located at addresses 180030H to 180038H. The value is cleared to 0 after power-on or reset, so be sure to set it.

                    **pattern name data size bit** :Pattern name data size bit (N0PNB, N1PNB, N2PNB, N3PNB, R0PNB): Specify the pattern name data size when displaying in cell format.

                :   |  |  |  |  |
                    | --- | --- | --- | --- |
                    | N0PNB | 180030H | bit 15 | For NBG0 (or for RBG1) |
                    | N1PNB | 180032H | bit 15 | For NBG1 |
                    | N2PNB | 180034H | bit 15 | For NBG2 |
                    | N3PNB | 180036H | bit 15 | For NBG3 |
                    | R0PNB | 180038H | bit 15 | For RBG0 |
                    |

                :   | xxPNB | Pattern name data size |
                    | --- | --- |
                    | ```  0 ``` | 2 words |
                    | ```  1 ``` | 1 word |

                    :   **[Note]** xx in the bit name is N0, N1, N2, N3, or R0.

                **Character number supplement bit** : Character number supplement bit: (N0CNSM, N1CNSM, N2CNSM, N3CNSM, R0CNSM) Specifies the character number assistance mode when the pattern name data size on the pattern name table is 1 word.

                :   |  |  |  |  |
                    | --- | --- | --- | --- |
                    | N0CNSM | 180030H | bit 14 | For NBG0 (or for RBG1) |
                    | N1CNSM | 180032H | bit 14 | For NBG1 |
                    | N2CNSM | 180034H | bit 14 | For NBG2 |
                    | N3CNSM | 180036H | bit 14 | For NBG3 |
                    | R0CNSM | 180038H | bit 14 | For RBG0 |
                    |

                :   | xxCNSM | process | |
                    | --- | --- | --- |
                    | ```  0 ``` | ```  mode 0 ``` | The character number in the pattern name data is 10 bits.  Reverse function can be specified for each character |
                    | ```  1 ``` | ```  mode 1 ``` | The character number in the pattern name data is 12 bits.  Reverse function not available |

                    :   **[Note]** xx in the bit name is N0, N1, N2, N3, or R0.

                **Special priority bit (for pattern name auxiliary data)** : Supplementary special priority bit: (N0SPR, N1SPR, N2SPR, N3SPR, R0SPR) Specify special priority bits as pattern name auxiliary data when the pattern name data size is 1 word.

            :   |  |  |  |  |
                | --- | --- | --- | --- |
                | N0SPR | 180030H | bit 9 | For NBG0 (or for RBG1) |
                | N1SPR | 180032H | bit 9 | For NBG1 |
                | N2SPR | 180034H | bit 9 | For NBG2 |
                | N3SPR | 180036H | bit 9 | For NBG3 |
                | R0SPR | 180038H | bit 9 | For RBG0 |

            :   For details on how to use this bit, see " **[11.2 Special Priority Function](p11_20.md)** ."

                **Special color operation bit (for pattern name auxiliary data)** :Supplementary special color calculation bit: (N0SCC, N1SCC, N2SCC, N3SCC, R0SCC) Specify special color operation bits as pattern name auxiliary data when the pattern name data size is 1 word.

                :   |  |  |  |  |
                    | --- | --- | --- | --- |
                    | N0SCC | 180030H | bit 8 | For NBG0 (or for RBG1) |
                    | N1SCC | 180032H | bit 8 | For NBG1 |
                    | N2SCC | 180034H | bit 8 | For NBG2 |
                    | N3SCC | 180036H | bit 8 | For NBG3 |
                    | R0SCC | 180038H | bit 8 | For RBG0 |

                :   For details on how to use this bit, please refer to " **[12.2 Special Color Calculation Functions"](p12_20.md)** .

                    **Supplementary palette number bit** : Supplementary palette number bit: (N0SPLT6~N0SPLT4, N1SPLT6~N1SPLT4, N2SPLT6~N2SPLT4, N3SPLT6~N3SPLT4, R0SPLT6~R0SPLT4) Specify the palette number bit as pattern name auxiliary data when the pattern name data size is 1 word. Three auxiliary palette number bits are added to the palette number bits of the pattern name data.

                    :   |  |  |  |  |
                        | --- | --- | --- | --- |
                        | N0SPLT6～N0SPLT4 | 180030H | bits 7-5 | For NBG0 (or for RBG1) |
                        | N1SPLT6～N1SPLT4 | 180032H | bits 7-5 | For NBG1 |
                        | N2SPLT6～N2SPLT4 | 180034H | bits 7-5 | For NBG2 |
                        | N3SPLT6~N3SPLT4 | 180036H | bits 7-5 | For NBG3 |
                        | R0SPLT6〜R0SPLT4 | 180038H | bits 7-5 | For RBG0 |

                    **Supplementary character number bit** : Supplementary character number bit: (N0SCN4~N0SCN0, N1SCN4~N1SCN0, N2SCN4~N2SCN0, N3SCN4~N3SCN0, R0SCN4~R0SCN0) Specify the character number bit as pattern name auxiliary data when the pattern name data size is 1 word. The auxiliary character number bits are added to the character number bits of the pattern name data by 5 bits.

                :   |  |  |  |  |
                    | --- | --- | --- | --- |
                    | N0SCN4～N0SCN0 | 180030H | bits 4-0 | For NBG0 (or for RBG1) |
                    | N1SCN4～N1SCN0 | 180032H | bits 4-0 | For NBG1 |
                    | N2SCN4～N2SCN0 | 180034H | bits 4-0 | For NBG2 |
                    | N3SCN4～N3SCN0 | 180036H | bits 4-0 | For NBG3 |
                    | R0SCN4～R0SCN0 | 180038H | bits 4-0 | For RBG0 |
