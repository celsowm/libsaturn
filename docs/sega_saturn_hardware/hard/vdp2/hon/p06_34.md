### ●Switching rotation parameters : RBG0 allows you to specify which of two rotation parameter tables to use, or to partially switch rotation parameters on a single display screen. You can choose how to use rotation parameters from the following four rotation parameter modes.

**Mode 0:**: Use rotation parameter A

**Mode 1:**: Use rotation parameter B

**Mode 2:**: Switch images according to the coefficient data read from the coefficient table of rotation parameter A

**Mode 3:**: Switch by rotation parameter window

:   For modes 0 and 1, images obtained by one set of rotation parameter tables are displayed. In modes 2 and 3, the image obtained by rotation parameter A and the image obtained by rotation parameter B are displayed on one screen.

:   For mode 2, set the RAKTE bit in the coefficient table control register to 1 to use the coefficient table for rotation parameter A. When the value of the most significant bit of the coefficient data read from the coefficient table is 0, the image obtained by rotation parameter A is displayed, and when it is 1, the image obtained by rotation parameter B is displayed as the RBG0 image. If the coefficient data for rotation parameter A is set to be read dot by dot, switching between two images can also be done dot by dot, but the coefficient data for rotation parameter B cannot be read dot by dot. lose.

:   In mode 3, the rotation parameter window bit in the rotation window control register switches between the two images. When that window is used as a transparency processing window, the image obtained by rotation parameter B is displayed in the part of the screen that is cut and made transparent, and the image obtained by rotation parameter A is displayed in other parts of RBG0. Display as an image.
