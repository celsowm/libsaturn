## ■4.4 Character pattern : The character pattern is a square pattern consisting of 1 or 4 cells, the size of which is specified in each register.

### ●Character size and cell placement : If a character pattern consists of 4 cells, the data of the cells used for the same character pattern must be stored consecutively in the character pattern table. Figure 4.7 shows the relationship between cell placement according to character size (number of cells in a character pattern) and the character pattern table.

:   **Figure 4.7 Cell placement according to character size**

    ```
    
    	Character pattern table 
    Specified─→┌────────┐ 
    Character  │        │  ●For 1 cell horizontally
    Pattern    │ Cell   │     x 1 cell vertically 
    Address    │ data 0 │    ┌──────┐┬ 
               ├────────┤    │      ││ 
               │        │    │Cell  ││8 dots 
               │ Cell   │    │data 0││ 
               │ data 1 │    └──────┘┴ 
               ├────────┤    ├──────┤ 
               │        │    8 dots 
               │ Cell   │    
               │ data 2 │    
               ├────────┤    ●For 1 cell horizontally
               │        │       x 1 cell vertically 
               │ Cell   │    ┌──────┬──────┐┬ 
               │ data 3 │    │      │      ││ 
               ├────────┤    │Cell  │Cell  ││ 
               │        │    │data 0│data 1││

               │ data 4 │    │      │      ││

    ```
