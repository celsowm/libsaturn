### ●Rotating scroll screen map register : The rotation scroll screen map register specifies the start address of the pattern name table placed on each plane of the screen according to rotation parameters A and B. This is a 16-bit write-only register located at addresses 180050H to 18006EH. The value is cleared to 0 after power-on or reset, so be sure to set it.
