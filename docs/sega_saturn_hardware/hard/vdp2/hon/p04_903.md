**Figure 4.17.3 Bitmap pattern structure, part 3**

### Bitmap size: 512 dots horizontally x 256 dots vertically

### Bitmap color number: 16 bits/dot (2048 colors, 32768 colors)

```

        Bit                                         
        15                                         0
        ┌──────────────────────────────────────────┐
+00000H │                   Dot 0-0                │
        ├──────────────────────────────────────────┤
+00002H │                   Dot 0-2                │
        ├──────────────────────────────────────────┤
                               :                    
                               :                    
                               :                    
                               :                    
        ├──────────────────────────────────────────┤
+3FFFEH │                 Dot 255-511              │
        ├──────────────────────────────────────────┤
        │                                          │
```

```

    Dot0     1     2          509   510   511

 Dot│     │     │     │     │     │     │     │       
   0│00000│00002│00004│ ... │003FC│003FC│003FE│
```

**[Note 1]**: The top left corner in the bitmap is dots 0-0, and from there to the right ~0-1, ~0-2, ~0-3,.... **[Note 2]**: The numbers in the bitmap are the VRAM addresses (hexadecimal) of each dot data, based on the VRAM address of the data of dots 0-0 and dots 0-1.
