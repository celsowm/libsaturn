## Chapter 13 Color offset function

---

:   The color offset function is a function that changes the screen color without changing the color RAM data by adding an offset value when outputting the color data of sprites and each scroll screen, and can be used for fade in, fade out, etc. Masu.

## ■13.1 Color offset specification : Two color offset values, Color Offset A and Color Offset B, can be set for each RGB, and you can specify which of these two to use for each screen. The color offset value is 9-bit data corresponding to each RGB, and if the color data resulting from adding each RGB is smaller than 00H, that color data is set to 00H and becomes larger than FFH. In all such cases, FFH is used.

:   Since the processing of the color offset function is performed after the processing of the color calculation function, the color offset value is added to the color data resulting from the color calculation. Also, since the color operation result screen is considered to be the top image screen, the color offset enable register is specified using the top image screen bits.

:   Color offset data is shown in Figure 13.1.

        ### ●Color offset enable register : The color offset enable register specifies whether to use the color offset function for each screen. This is a 16-bit write-only register located at address 180110H. The value is cleared to 0 after power-on or reset, so be sure to set it.

            **Color offset enable bit** : Color offset enable bit: (N0COEN, N1COEN, N2COEN, N3COEN, R0COEN, BKCOEN, SPCOEN) Specify whether to use the color offset function.

        :   |  |  |  |  |
            | --- | --- | --- | --- |
            | N0COEN | 180110H | bit 0 | For NBG0 (or for RBG1) |
            | N1COEN | 180110H | bit 1 | For NBG1 (or for EXBG) |
            | N2COEN | 180110H | bit 2 | For NBG2 |
            | N3COEN | 180110H | bit 3 | For NBG3 |
            | R0COEN | 180110H | bit 4 | For RBG0 |
            | BKCOEN | 180110H | bit 5 | For BACK |
            | SPCOEN | 180110H | bit 6 | for sprites |

        :   | xxCOEN | process |
            | --- | --- |
            | 0 | Do not use color offset function |
            | 1 | Use the color offset function |

            :   **[Note]** xx in the bit name is N0, N1, N2, N3, R0, BK, or SP.

        :   If you are using the color calculation function, specify it using the color offset enable bit on the screen on the top image side.
