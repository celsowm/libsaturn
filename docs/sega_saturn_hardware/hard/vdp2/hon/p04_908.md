**Figure 4.17.8 Bitmap pattern structure, Part 8**

### Bitmap size: 512 dots horizontally x 512 dots vertically

### Bitmap color count: 32 bits/dot (16.77 million colors)

```

        Bit                                         
        15                                         0
        ┌──────────────────────────────────────────┐
+00000H │ Dot 0-0 (upper word) │
        ├──────────────────────────────────────────┤
+00002H │ Dots 0-0 (lower word) │
        ├──────────────────────────────────────────┤
+00004H │ Dot 0-1 (upper word) │
        ├──────────────────────────────────────────┤
                            :                       
                            :                       
                            :                       
                            :                       
        ├──────────────────────────────────────────┤
+FFFFCH │ Dots 511-511 (upper word) │
        ├──────────────────────────────────────────┤
+FFFFEH │ Dots 511-511 (lower word) │
        ├──────────────────────────────────────────┤
        │ │
```

▽

```

    Dot0     1     2          509   510   511         
    ┌─────┬─────┬─────┬─   ─┬─────┬─────┬─────┐       
 Dot│     │     │     │     │     │     │     │       
   0│00000│00004│00008│ ... │007F4│007F8│007FC│       
    │     │     │     │     │     │     │     │       
    ├─────┼─────┼─────┼─   ─┼─────┼─────┼─────┤       
    │     │     │     │     │     │     │     │       
   1│00800│00804│00808│ ... │00FF4│00FF8│00FFC│       
    │     │     │     │     │     │     │     │       
    ├─────┴─────┴─────┴─   ─┴─────┴─────┴─────┤       
   .                                                  
   .                                            Bitmap
   .                                                  
    ├─────┬─────┬─────┬─   ─┬─────┬─────┬─────┤       
    │     │     │     │     │     │     │     │       
510 |FF000|FF004|FF008| ... |FFFF4|FFFF8|FFFFC|       
    │     │     │     │     │     │     │     │       
    ├─────┼─────┼─────┼─   ─┼─────┼─────┼─────┤       
    │     │     │     │     │     │     │     │

    └─────┴─────┴─────┴─   ─┴─────┴─────┴─────┘
```

**[Note 1]**: The top left corner in the bitmap is dots 0-0, and from there to the right ~0-1, ~0-2, ~0-3,.... **[Note 2]**: The numbers in the bitmap are the VRAM addresses (hexadecimal) of each dot data (upper word), based on the VRAM address of dot 0-0 data (upper word).
