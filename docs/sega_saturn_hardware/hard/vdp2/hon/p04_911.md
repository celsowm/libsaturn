**Figure 4.17.11 Bitmap pattern configuration, Part 11**

### Bitmap size: 1024 dots horizontally x 256 dots vertically

### Bitmap color number: 16 bits/dot (2048 colors, 32768 colors)

```

        Bit                                         
        15                                         0
        ┌──────────────────────────────────────────┐
+00000H │                Dot 0-0                   │
        ├──────────────────────────────────────────┤
+00002H │                Dot 0-2                   │
        ├──────────────────────────────────────────┤
                            :                       
                            :                       
                            :                       
                            :                       
        ├──────────────────────────────────────────┤
+7FFFEH │ Dot 255-1023 │
        ├──────────────────────────────────────────┤
        │                                          │
```
