---

### ●Vertical cell scroll table data access : When using the vertical cell scroll function in NBG0 and NBG1, it is necessary to read the vertical cell scroll table data in addition to pattern name data and character pattern data (bitmap pattern data). Vertical cell scroll table data read access is required once per cycle per page. Vertical cell scroll table data read access for NBG0 must be specified at timing T0 or T1, and vertical cell scroll table data read access for NBG1 must be specified at timing between T0 and T2. yeah. Also, accesses for NBG0 and NBG1 must be made to the same bank, and access for NBG0 must be specified first. When specifying the same vertical cell scroll table data read access for multiple banks, the access timing must be specified at the same time. Figure 3.5 shows the access specification restrictions for vertical cell scroll table data.
