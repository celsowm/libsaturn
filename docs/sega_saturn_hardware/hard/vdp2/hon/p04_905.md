**Figure 4.17.5 Bitmap pattern structure, Part 5**

### Bitmap size: 512 dots horizontally x 512 dots vertically

### Bitmap color count: 4 bits/dot (16 colors)

```

        Bit                                          
        15       12 11       8 7        4 3         0
        ┌──────────┬──────────┬──────────┬──────────┐
+00000H │ Dot 0-0  │ Dot 0-1  │ Dot 0-2  │ Dot 0-3  │
        ├──────────┼──────────┼──────────┼──────────┤
+00002H │ Dot 0-4  │ Dot 0-5  │ Dot 0-6  │ Dot 0-7  │
        ├──────────┼──────────┼──────────┼──────────┤
        │    :     │    :     │    :     │    :     │
             :          :          :          :      
             :          :          :          :      
        │    :     │    :     │    :     │    :     │
        ├──────────┼──────────┼──────────┼──────────┤
+1FFFEH |Dot255-508|Dot255-509|Dot255-510|Dot255-511|
        ├──────────┴──────────┴──────────┴──────────┤
        │                                           │
```
