**Figure 4.17.14 Bitmap pattern configuration, Part 14**

### Bitmap size: 1024 dots horizontally x 512 dots vertically

### Bitmap color count: 8 bits/dot (256 colors)

```

        Bit                                          
        15                  8 7                     0
        ┌────────────────────┬──────────────────────┐
+00000H │       Dot 0-0      │        Dot 0-1       │
        ├────────────────────┼──────────────────────┤
+00002H │       Dot 0-2      │        Dot 0-3       │
        ├────────────────────┼──────────────────────┤
                   :         │           :           
                   :         :           :           
                   :         :           :           
                   :         │           :           
        ├────────────────────┼──────────────────────┤
+7FFFEH │    Dot 511-1022    │     Dot 511-1023     │
        ├────────────────────┴───────────┴──────────┤
        │                                           │
```
