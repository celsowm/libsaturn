## Chapter 3 Functions

---

### ■3.1 CPU : The main CPU is equipped with a 32-bit RISC chip with built-in DSP function, and the sound block section is equipped with a 16-bit CPU MC68EC000. In addition, SH-1 is installed on the subsystem side. : **Table 3.1 CPU specifications** | SH-2 | ``` ・RISC type instruction set ・ Internal, external 32-bit bus ・ Cache 4K bytes ・ Clock 28.6MHz Note 1 ・ Built-in multiplier/divider ``` | | SH-1 | ``` ・RISC type instruction set ・ Built-in A/D converter ・ Internal 32-bit bus, external 16-bit bus ・ Clock 20MHz ・ Cache 4K bytes ・ Built-in multiplier ``` | | MC68EC000 | ``` ・Internal 16-bit bus, external 16-bit bus ・ CISC type instruction set ・ Clock 11.3MHz ``` | : **note**: **Table 3.1.1 SH-2 clock details** | Screen display mode | operating clock | | 320 dot mode (NTSC system) | 26.8741MHz | | 352 dot mode (NTSC system) | 28.6364MHz | | In 320 dot mode (PAL method) | 26.6877MHz | | 352 dot mode (PAL system) | 28.4377MHz |
