# Sega Saturn Overview Manual

---

### Introduction : This manual provides an overview of the hardware for the Sega Saturn, a multimedia-compatible home game console equipped with a 32-bit **RISC** (Reduced **Instruction** **Set** **Computer** ) processor. This manual provides an overview of the features and functions of the Sega Saturn for game software developers.
