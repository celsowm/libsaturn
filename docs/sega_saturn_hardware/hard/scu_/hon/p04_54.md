# MOV SImm,[d] : ### Transfer (SImm→[destination])

**Operation details**: Transfers SIMm data to the RAM or register specified by [destination].: SImm data is signed 8-bit data.

**descriptive formula**: label: MOV SImm,[Destination]: Destination = MC0~MC3,RX,PL,RA0,WA0,LOP,TOP,TC0~TC3
