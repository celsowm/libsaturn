## ■3.2 DMA control register : The DMA control register consists of the following registers.

:   - [Level 2-0 DMA set register](p03_02.md)- [DMA permission register](p03_02.md)- [DMA mode, address update, activation factor selection register](p03_02.md)

On the other hand, in indirect mode, the address containing the transfer source address of the first DMA transfer is stored. While DMA is operating, registers at that level are write-protected. All address values are expressed in bytes.
