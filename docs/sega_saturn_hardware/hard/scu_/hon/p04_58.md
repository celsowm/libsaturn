# LPS : ### 1 step repeat execution

**Operation details**: Repeat the next step until the [LOP] register becomes 0.

**descriptive formula**: label: LPS **instruction code**: | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | | 31 | 30 | 29 | 28 | 27 | | | | | | | | | | | | | | | | | | | | | | | | | | | 0 | | 1 | 1 | 1 | 0 | 1 | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | − | **flag**: LOP;LOP<> It is decremented only when it is 0 (other than 0). It ends when LOP=0. **remarks**: After processing is completed, the PC executes LOP+1 times and exits.
