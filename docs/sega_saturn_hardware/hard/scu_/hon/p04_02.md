## ■4.2 Command list

Below is a list of instructions used in SCU-DSP.

## [◆Arithmetic instructions](p04_05.md) [ALU control](p04_51.md) **[NOP](p04_51.md)** I won't do anything. **[AND](p04_51.md)** Performs a logical AND between [ACL] and [PL]. **[OR](p04_51.md)** Performs the logical OR of [ACL] and [PL]. **[XOR](p04_51.md)** Performs exclusive OR of [ACL] and [PL]. **[ADD](p04_51.md)** Add [ACL] and [PL]. **[SUB](p04_51.md)** Subtract [PL] from [ACL]. **[AD2](p04_51.md)** Add [ACH][ACL] and [PH][PL]. **[S.R.](p04_51.md)** Shift [ACL] to the right by 1 bit and store the LSB in the carry flag. **[RR](p04_51.md)** Rotate [ACL] to the right by 1 bit and store the LSB in the carry flag. **[SL](p04_51.md)** Shift [ACL] to the left by 1 bit and store 0 in the LSB of [ACL] and the MSB in the carry flag. **[R.L.](p04_51.md)** Rotate [ACL] to the left by 1 bit and store the MSB in the carry flag. **[RL8](p04_51.md)** Rotate [ACL] to the left by 8 bits and store b24 in the carry flag. [X-Bus control](p04_52.md) **[NOP](p04_52.md)** I won't do anything. **[MOV[s],X](p04_52.md)** Transfer data from data RAM to [RX]. **[MOV MUL,P](p04_52.md)** Transfer the data of [MULTIPLIER] to [PH][PL]. **[MOV[s],P](p04_52.md)** Transfer data from data RAM to [PL]. [Y-Bus control](p04_53.md) **[NOP](p04_53.md)** I won't do anything. **[MOV[s],Y](p04_53.md)** Transfer data from data RAM to [RY]. **[CLR A](p04_53.md)** Clear [ACH] and [ACL] to 0. **[MOV ALU,A](p04_53.md)** Transfer the data of [ALU] to [ACH][ACL]. **[MOV[s],A](p04_53.md)** Transfer data from data RAM to [ACL]. [D1-Bus control](p04_54.md) **[NOP](p04_54.md)** I won't do anything. **[MOV SImm,[d]](p04_54.md)** Stores the SImm (short immediate) data in the data RAM or register specified by [d]. **[MOV [s],[d]](p04_54.md)** Transfers data from the data RAM or register specified by [s] to the data RAM or register specified by [d]. [◆Load immediate instruction](p04_55.md) **[MVI Imm,[d]](p04_55.md)** Stores the Imm (immediate) data in the data RAM or register specified by [d]. **[MVI Imm,[d],Z](p04_55.md)** Only when Z (zero flag) of the program control port is 1, Imm (immediate) data is stored in the data RAM or register specified by [d]. **[MVI Imm,[d],NZ](p04_55.md)** Only when Z (zero flag) of the program control port is 0, Imm (immediate) data is stored in the data RAM or register specified by [d]. **[MVI Imm,[d],S](p04_55.md)** Only when S (sign flag) of the program control port is 1, Imm (immediate) data is stored in the data RAM or register specified by [d]. **[MVI Imm,[d],NS](p04_55.md)** Only when S (sign flag) of the program control port is 0, Imm (immediate) data is stored in the data RAM or register specified by [d]. **[MVI Imm,[d],C](p04_55.md)** Only when C (carry flag) of the program control port is 1, Imm (immediate) data is stored in the data RAM or register specified by [d]. **[MVI Imm,[d],NC](p04_55.md)** Only when C (carry flag) of the program control port is 0, Imm (immediate) data is stored in the data RAM or register specified by [d]. **[MVI Imm,[d],TO](p04_55.md)** Only when TO (D0 bus DMA execution flag) of the program control port is 1, Imm (immediate) data is stored in the data RAM or register specified by [d]. **[MVI Imm,[d],NTO](p04_55.md)** Only when TO (D0 bus DMA execution flag) of the program control port is 0, Imm (immediate) data is stored in the data RAM or register specified by [d]. **[MVI Imm,[d],ZS](p04_55.md)** Only when either Z (zero flag) or S (sign flag) of the program control port is 1, Imm (immediate) data is stored in the data RAM or register specified by [d]. **[MVI Imm,[d],NZS](p04_55.md)** Only when Z (zero flag) and S (sign flag) of the program control port are both 0, Imm (immediate) data is stored in the data RAM or register specified by [d]. [◆DMA instruction](p04_56.md) **[DMA D0,[RAM],SImm](p04_56.md)** Set the SImm (short immediate) data as a transfer counter in the transfer word counter ([TN0]), and use the D0 bus to transfer the data from the outside to the RAM area specified by [RAM]. The transfer start address ([RA0]) and transfer word counter ([TN0]) are updated to the values at the end of the transfer. **[DMA [RAM],D0,SImm](p04_56.md)** Set the SImm (short immediate) data as a transfer counter in the transfer word counter ([TN0]), and transfer the data externally from the RAM area specified by [RAM] using the D0 bus. The transfer start address ([WA0]) and transfer word counter ([TN0]) are updated to the values at the end of the transfer. **[DMA D0,[RAM],[s]](p04_56.md)** Set the data in the data RAM specified by [s] to the transfer word counter ([TN0]) as a transfer counter, and use the D0 bus to externally transfer the data to the RAM area specified by [RAM]. forward. The transfer start address ([RA0]) and transfer word counter ([TN0]) are updated to the values at the end of the transfer. **[DMA [RAM],D0,[s]](p04_56.md)** Set the data in the data RAM specified by [s] to the transfer word counter ([TN0]) as a transfer counter, and transfer the data externally from the RAM area specified by [RAM] using the D0 bus. forward. The transfer start address ([WA0]) and transfer word counter ([TN0]) are updated to the values at the end of the transfer. **[DMAH D0,[RAM],SImm](p04_56.md)** Set the SImm (short immediate) data as a transfer counter in the transfer word counter ([TN0]), and transfer the data from the outside to the RAM area specified by [RAM] using the D0 bus. The transfer start address ([RA0]) and transfer word count counter ([TN0]) retain the values they had when the transfer started. **[DMAH [RAM],D0,SImm](p04_56.md)** Set the SImm (short immediate) data as a transfer counter in the transfer word counter ([TN0]), and transfer the data externally from the RAM area specified by [RAM] using the D0 bus. The transfer start address ([WA0]) and transfer word count counter ([TN0]) retain the values they had when the transfer started. **[DMAH D0,[RAM],[s]](p04_56.md)** Set the data in the data RAM specified by [s] to the transfer word counter ([TN0]) as a transfer counter, and use the D0 bus to externally transfer the data to the RAM area specified by [RAM]. forward. The transfer start address ([RA0]) and transfer word count counter ([TN0]) retain the values they had when the transfer started. **[DMAH [RAM],D0,[s]](p04_56.md)** Set the data in the data RAM specified by [s] to the transfer word counter ([TN0]) as a transfer counter, and transfer the data externally from the RAM area specified by [RAM] using the D0 bus. forward. The transfer start address ([WA0]) and transfer word count counter ([TN0]) retain the values they had when the transfer started. [◆JUMP instruction](p04_57.md) **[JMP Imm](p04_57.md)** Move to the address indicated by Imm (immediate). **[JMP Z,Imm](p04_57.md)** When Z (zero flag) of the program control port is 1, move to the address indicated by Imm (immediate). **[JMP NZ,Imm](p04_57.md)** When Z (zero flag) of the program control port is 0, move to the address indicated by Imm (immediate). **[JMP S,Imm](p04_57.md)** When S (sign flag) of the program control port is 1, move to the address indicated by Imm (immediate). **[JMP NS,Imm](p04_57.md)** When S (sign flag) of the program control port is 0, move to the address indicated by Imm (immediate). **[JMP C,Imm](p04_57.md)** When C (carry flag) of the program control port is 1, it moves to the address indicated by Imm (immediate). **[JMP NC,Imm](p04_57.md)** When C (carry flag) of the program control port is 0, move to the address indicated by Imm (immediate). **[JMP TO,Imm](p04_57.md)** When TO (D0 bus DMA execution flag) of the program control port is 1, move to the address indicated by Imm (immediate). **[JMP NTO,Imm](p04_57.md)** When TO (D0 bus DMA execution flag) of the program control port is 0, move to the address indicated by Imm (immediate). **[JMP ZS,Imm](p04_57.md)** When either Z (zero flag) or S (sign flag) of the program control port is 1, move to the address indicated by Imm (immediate). **[JMP NZS,Imm](p04_57.md)** When Z (zero flag) and S (sign flag) of the program control port are both 0, move to the address indicated by Imm (immediate). [◆LOOP BOTTOM instruction](p04_58.md) **[BTM](p04_58.md)** When the loop counter ([LOP]) is other than 0, the top address register ([TOP]) is stored in the program counter and the loop counter ([LOP]) is decremented. When it is 0, it does nothing. **[LPS](p04_58.md)** When the loop counter ([LOP]) is other than 0, stop the program counter, execute the next instruction, decrement the loop counter ([LOP]), and repeat until the loop counter reaches 0. [◆END command](p04_59.md) **[END](p04_59.md)** Stop the program and reset the EX (program execution control flag) of the program control port. **[ENDI](p04_59.md)** Stop the program, reset EX (program execution control flag) of the program control port, and set E (program end interrupt flag). ●Description of DSP program For constants or assembler descriptions, please refer to the " [SCU DSP Arambula User's Manual](dspasm.md) " in the appendix.
