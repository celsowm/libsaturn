## ■4.1 TV mode selection register : The TV mode selection register (TVMR, TV mode register) specifies V blank erase permission and TV display mode. This is a 16-bit write-only register located at address 100000H. The value will be undefined after the power is turned on or reset, so be sure to set the TV display mode. Fix unused bits to 0.

**V blank erase write enable bit:** V blank erase/write enable (VBE), bit3

- When VBE=1, erase write is performed during V blank. VBE=1 can be set only when FCM=1 and FCT=1 are written. For more information, see **[4.2 Frame Buffer Switching Mode Register](p04_12.md)** .

- When setting the VBE value to 0 or 1, be sure to set the TVM with the same value as before setting at the same time.

- Set VBE immediately after the V blank IN interrupt. Access is prohibited from the first H blank IN interrupt after the V blank IN interrupt until the next H blank IN interrupt.

**TV mode selection bit:** TV mode select (TVM), bit2~0

- Specify the TV display mode.

- Please refer to " **[Screen mode and display range](p01_20.md)** " for the coordinate values of the displayed area.

- When TVM=010B(2), the frame buffer is only 512 pixels wide x 256 pixels high, so if you tilt the screen too much, a transparent area will appear on the display screen.

- When specifying HDTV (TVM=100B(4)), only non-interlace can be set, and when specifying rotated display (TVM=010B(2), 011B(3)), only non-interlace and single density interlace can be set. Disable double-dense interlacing (DIE bit = 0) using the frame buffer switching mode register. For details, see " **[4.2 Frame Buffer Switching Mode Register](p04_12.md)** ".

- Set TVM between the second H blank IN interrupt after the V blank IN interrupt and the H blank IN interrupt immediately after the V blank OUT interrupt.

- The functions of each bit are as follows, but there are restrictions on the combinations of bits, so please strictly adhere to the setting values in Table 4.2.

**Bit 2: HDTV enable bit**: 0=NTSC, PAL: 1=HDTV, 31kHz

**Bit 1: Frame buffer rotation enable bit**: 0=no rotation: 1=rotation

**Bit 0: Bit width selection bit**: 0=16bit/pixel: 1=8bit/pixel
