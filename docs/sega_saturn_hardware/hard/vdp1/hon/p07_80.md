## ■7.8 Polyline drawing command : The polyline drawing command draws a rectangle into the frame buffer. The inside of the rectangle is not filled. When the end bit is 0B and the command selection bit is 0101B, it is a polyline drawing command. The contents of the command table are as follows:

:   The polyline drawing command is defined as follows.

- Setting the end bit to 0B and the command selection bit to 0101B makes it a polyline drawing command. - Specify the jump format. When the jump format is Assign or Call, divide the address of the next command table to be processed by 8H and set it to CMDLINK. - Set pre-clipping. Specify whether to enable or disable it, considering the clipping area and the drawing position of the part. - Specify the user clipping enable bit and clipping mode. Specifies whether user clipping is outside or inside in clipping mode. - Set mesh enable. When mesh is enabled, the entire polyline may not be drawn depending on its position and shape. - Set MSB on for shade or window processing in VDP2. - Set the color mode to 000B. Set the color code to **non-textured color (CMDCOLR)** . - Specify color operation. Color calculation is valid when non-texture color is in RGB mode. If you do not want to perform color calculations, specify Replace. When performing Gouraud shading processing, divide the address of the Gouraud shading table by 8H and specify it. Gouraud shading processing is effective when the non-texture color is in RGB mode. - When applying translucency to a polyline, two lines overlap at each vertex, so the result is two degrees of translucency, resulting in 3/4 of the original painting + 1/4 of the base. - When performing shadow processing on a polyline, each vertex will have two lines overlapping, so the shadow will be cast twice and the brightness will be halved. - Set the upper left coordinate of the rectangle to be drawn as the vertex (A) (CMDXA, CMDYA), the upper right coordinate as the vertex (B) (CMDXB, CMDYB), the lower right coordinate as the vertex (C) (CMDXC, CMDYC), and the lower left coordinate as Define at vertex (D) (CMDXD, CMDYD). The positional relationship of the four vertices is arbitrary, so you can specify rotation and twist by specifying apex (A), apex (B), apex (C), and apex (D). - **Note:** If you set two vertices to the same coordinates, the polyline will be drawn as a triangle. If you set 4 vertices to the same coordinates, the polyline will be drawn with 1 pixel.
