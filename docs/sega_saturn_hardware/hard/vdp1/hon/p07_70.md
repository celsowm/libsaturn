## ■7.7 Polygon drawing commands : The polygon drawing commands draw rectangles into the frame buffer. Fills the inside of the rectangle with the specified color. When the end bit is 0B and the command selection bit is 0100B, it is a polygon drawing command. The contents of the command table are as follows:

:   The polygon drawing command is defined as follows.

- Setting the end bit to 0B and the command selection bit to 0100B makes it a polygon drawing command.

- Specify the jump format. When the jump format is Assign or Call, divide the address of the next command table to be processed by 8H and set it to CMDLINK.

- Set pre-clipping. Specify whether to enable or disable it, considering the clipping area and the drawing position of the part.

- Specify the user clipping enable bit and clipping mode. Specifies whether user clipping is outside or inside in clipping mode.

- Set mesh enable. Set MSB on for shade or window processing in VDP2.

- Set the color mode to 000B. Set the color code to **non-textured color (CMDCOLR)** .

- Specify color operation. Color calculation is valid when non-texture color is in RGB mode. If you do not want to perform color calculations, specify Replace. When performing Gouraud shading processing, divide the address of the Gouraud shading table by 8H and specify it. Gouraud shading processing is effective when the non-texture color is in RGB mode.

- Set the upper left coordinates of the rectangle to be drawn as the vertex (A) (CMDXA, CMDYA), the upper right coordinates as the vertex (B) (CMDXB, CMDYB), the lower right coordinates as the vertex (C) (CMDXC, CMDYC), and the lower left coordinate as Define at vertex (D) (CMDXD, CMDYD). The positional relationship of the four vertices is arbitrary, so you can specify rotation and twist by specifying apex (A), apex (B), apex (C), and apex (D).

- **Note:** If you set two vertices to the same coordinates, the polygon will be drawn as a triangle. If you set 4 vertices to the same coordinates, the polygon will be drawn with 1 pixel.
