**VDP1 User's Manual**

## Chapter 9 Precautions for use

---

:   Precautions for use are as follows.

### ● VDP1 general - For normal, high resolution, HDTV, and double-dense interlacing, frame buffer rotation reading is prohibited. **[ [reference](p01_20.md) ]** - The CPU can only access the drawing framebuffer. **[ [reference](p02_10.md) ]** ### ● System register - DMA access to system registers is prohibited. Please be sure to use Word Access. **[ [reference](p02_12.md) ]** - After turning on the power, be sure to set the system registers. **[ [reference](p02_12.md) ]** - Be sure to set unused bits of system registers to 0. **[ [reference](p02_12.md) ]** - When reading the frame buffer rotationally, be sure to set DIE = 0. Rotational reading with double-dense interlacing is prohibited. **[ [reference](p01_20.md) ]** - Please note that an undefined surface will be displayed in the first frame immediately after changing the DIE bit. **[ [reference](p04_12.md) ]** - When changing TVM bits, it is necessary to mask the frame buffer. When changing, one frame of the irregular surface will be displayed. **[ [reference](p04_11.md) ]** - For double-dense interlacing, set FCM=0 and FCT=0. Field switching is only possible at 1/60 seconds. **[ [reference](p04_12.md) ]** - Erase write area settings are (upper left coordinates XA)＜ Please set so that (lower right coordinate XC) and (upper left coordinate YA) ≦ (lower right coordinate YC). **[ [reference](p04_14.md) ]** ### ● Command - Relative coordinates must be set after the power is turned on. **[ [reference](p07_30.md) ]** - The range that can be set for clipping coordinates is from (0, 0) to (1023, 511). **[ [reference](p07_10.md) ]** - The range of clipping coordinates is (upper left coordinate XA) ≦ (lower right coordinate XC) and (upper left coordinate YA) ≦ (lower right coordinate YC). **[ [reference](p07_20.md) ]** - For clipping, set appropriate values according to the screen mode set with the TVM bit. **[ [reference](p07_10.md) ]** - Be sure to set the user clipping area inside the system clipping area. Collinearity can be set. **[ [reference](p07_20.md) ]** - The upper left coordinate of the system clipping area is fixed to (0, 0) by hardware. **[ [reference](p07_10.md) ]** - Set unused bits in the words you are using to 0 in the command table. **[ [reference](p06_10.md) ]** - Calls (calls, jump calls, skip calls) within command subroutines are prohibited. **[ [reference](p06_10.md) ]** - Returns (returns, jump returns, skip returns) within the command main routine are prohibited. **[ [reference](p06_10.md) ]** - Zoom point values can only be 0H, 5H, 6H, 7H, 9H, AH(10), BH(11), DH(13), EH(14), FH(15). Any other settings are prohibited. **[ [reference](p06_10.md) ]** - When HSS=1, the end code of the original picture is ignored regardless of whether the sprite is enlarged or reduced. **[ [reference](p06_31.md) ]** - Set the lower 2 bits of CMDLINK to 00. **[ [reference](p06_20.md) ]** - Set the lower two bits of the lookup table to 00. **[ [reference](p02_12.md) ]** - When setting the color bank, set the lower 4 bits of the color bank data to 0000. **[ [reference](p06_40.md) ]** - When using non-texture, set ECD=1, SPD=1, and color mode=0. **[ [reference](p06_40.md) ]** - When performing color calculations without texture, set RGB data (8000H or higher) to the non-texture color. **[ [reference](p06_40.md) ]** - When setting to RGB mode and using 7FFFH data for the original picture, please set ECD = 0. **[ [reference](p06_37.md) ]** - When setting to RGB mode and using data of 0000H for the original picture, please set SPD = 0. **[ [reference](p06_37.md) ]** - When set to RGB mode, setting the frame buffer to 8 bits/pixel is prohibited. The only color modes that allow 8 bits/pixel are modes 0, 1, 2, 3, and 4. **[ [reference](p02_11.md) ]** - When setting the frame buffer to 8 bits/pixel, set the color calculation mode to 0. Only replacement is possible. Other color operations are prohibited. **[ [reference](p02_11.md) ]** - When the frame buffer is set to 8 bits/pixel, the upper 8 bits of non-textured colors are ignored. At this time, use of RGB data is prohibited. **[ [reference](p02_11.md) ]** - Do not set the MSB on bit (MON) to 1 when the frame buffer is set to 8 bits/pixel. **[ [reference](p02_11.md) ]** - When the MSB on bit (MON) is set to 1, set the color calculation mode to 0. **[ [reference](p06_38.md) ]** - Store the command table at address 000000H of VRAM. **[ [reference](p02_10.md) ]**
