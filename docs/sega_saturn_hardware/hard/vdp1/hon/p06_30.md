**VDP1 User's Manual/Chapter 6 Command Table**

---

## ■6.3 CMDPMOD (drawing mode word) : CMDPMOD is a word that controls enabling/disabling clipping, mesh processing, specifying transparency codes, specifying color mode, color operations, and shade processing. It is located in 2 bytes (16 bits) starting from the first address +04H of the command table, and the bit configuration is as follows. Set unused bits to 0.

Specify this bit if you want to use that feature. For details, please refer to the VDP2 manual " [Chapter 9 Sprite Data](../../vdp2/hon/p09_10.md) " and " [Chapter 14 Shadow Function](../../vdp2/hon/p14_10.md) ". **[High speed shrink:](p06_31.md)** high speed shrink(HSS), bit 12 : Select whether to give priority to speed or accuracy when drawing rectangular sprites and deformed sprites in reduced size. **[Preclipping disable:](p06_32.md)** preclipping disable(Pclp), bit 11 : Specifies whether or not to disable the coordinate calculation process that determines whether clipping is necessary. **[User clipping enable bit:](p06_32.md)** user clipping enable bit(Clip), bit 10 : When using a part drawing command, specify whether or not to draw the part according to the user clipping coordinates that have already been set. **[Clipping mode bit:](p06_32.md)** clipping mode bit(Cmod), bit 9 : When user clipping is enabled (Clip=1), select whether to draw inside or outside the user clipping coordinates. **[Mesh enable bit:](p06_33.md)** mesh enable bit(Mesh), bit 8 : Specifies whether to perform mesh processing when using part drawing commands. **[End-code disable bit:](p06_34.md)** end-code disable (ECD), bit 7 : Specifies whether to disable the character pattern end code. **[Transparent pixel disable bit:](p06_35.md)** see-through pixel disable (SPD), bit 6 : Specifies whether to disable transparent pixels in the character pattern. **[Color mode bit:](p06_36.md)** color mode bit, bits 5 to 3 : Specify the number of colors and expression method for drawing sprites. **[Color calculation bit:](p06_37.md)** color calculation bit, bits 2 to 0 : Specifies color operations for Gouraud shading, shadow, semi-brightness, and translucency.
