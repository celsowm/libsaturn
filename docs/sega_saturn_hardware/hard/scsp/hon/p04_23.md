**SCSP User's Manual/4.3 Sound source register**

---

### ■FM modulation control register **SOUS[15:0](R/W) ; SOUnd Stack**: Data buffer for slot output. A 64-word ring buffer can hold two generations of sampling data. This is used for modulation and inter-slot addition operations. **MDL[3:0](R/W) ; MoDuLation level**: Specifies the influence of the modulation input source on the modulation (modulation depth). : **Table 4.8 Modulation degree by register setting value**: | | | | | | | | | | | | | | | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | | MDL[3:0] | ``` 0-4 ``` | ``` 5 ``` | ``` 6 ``` | ``` 7 ``` | ``` 8 ``` | ``` 9 ``` | ``` A ``` | ``` B ``` | ``` C ``` | ``` D ``` | ``` E ``` | ``` F ``` | | Modulation depth (±nπ) | 0 | 1/16 | 1/8 | 1/4 | 1/2 | 1 | 2 | 4 | 8 | 16 | 32 | 64 | **MDXSL[5:0](R/W) ;MoDulation input-X SeLect**: Specifies the source used as modulation input X. Specify the source slot of modulation input X relative to the current slot using a two's complement number. Also, when this value is within the range of "1CH" to "3BH", it indicates the latest generation, and when it is outside the range, it indicates that the source is one sample older than the latest generation (see [Table 4.9](p04_fm3.md) ). **MDYSL[5:0](R/W);MoDulation input-Y SeLect**: Specifies the source used as modulation input Y. Specify the source slot of modulation input Y relative to the current slot using a two's complement number. Also, when this value is within the range of "1CH" to "3BH", it indicates the latest generation, and when it is outside the range, it indicates that the source is one sample older than the latest generation (see [Table 4.9](p04_fm3.md) ). **STWINH(R/W) ; STack Write INHibit**: When this bit is "1B", writing the slot output to the sound stack (SOUS) is prohibited. Normally, "0B" is fine.
