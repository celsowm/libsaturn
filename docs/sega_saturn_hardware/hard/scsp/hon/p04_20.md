**SCSP User's Manual/4.2 Sound source register**

---

### ■4.2 Sound source register : The structure of the sound source register is as shown below (Table 4.9). The contents of each register will be explained according to this configuration. Regarding the symbols added after the register name,

:   - (R) is read-only- (W) is for writing only- (R/W) can read and write

:   are expressed respectively.

:   Also, when reading data from a write-only register (bit), the value will be "0B". When writing data to a read-only register (bit), be sure to write "0B".

**List 4.7 Sound source register allocation** **● [Loop control register](p04_21.md) :**: KYONEX, KYONB, SBCTL, SSCTL, SA, LSA, LEA, PCM8B, LPCTL **● [EG register](p04_22.md) :**: EGHOLD, AR, D1R, D2R, RR, DL, KRS, LPSLNK **● [FM modulation control register](p04_23.md) :**: SOUS, MDL, MDXSL, MDYSL, STWINH: → [When using the FM sound source method](p04_fm1.md) **● [Volume register](p04_24.md) :**: TL, SDIR **● [PITCH register](p04_25.md) :**: OCT, FNS **● [LFO register](p04_26.md) :**: LFORE, LFOF, ALFOWS, ALFOS, PLFOWS, PLFOS **● [MIXER register](p04_27.md) :**: IMXL, ISEL, DISDL, DIPAN, EFSDL, EFPAN, MVOL, DAC18B **● [Slot status register](p04_28.md) :**: MSLC, CA **● [Sound memory configuration register](p04_29.md) :**: MEM4MB **● [MIDI register](p04_2a.md) :**: MIBUF, MIOVF, MIFULL, MOFULL, MOEMP, MOBUF **● [Timer register](p04_2b.md) :**: TACTL, TIMA, TBCTL, TIMB, TCCTL, TIMC **● [Interrupt control register](p04_2c.md) :**: SCIPD, SCIEB, SCIRE, SCILV0, SCILV1, SCILV2, MCIPD, MCIEB, MCIRE **● [DMA transfer register](p04_2d.md) :**: DGATE, DDI, DEXE, DMEA, DRGA, DTLG
