## ■4.3 DSP memory control register : Delay processing is the basis of DSP effect processing. Delay is achieved by storing input data in memory and reading it out with a time difference. This storage area is called a ring buffer. You can set the ring buffer area using the "RBL" and "RBP" registers according to the number of effect programs used simultaneously and the delay time of the effects.

**RBL[1:0](W); Ring Buffer Length**: Specify the length of the ring buffer.

:   **Table 4.34 RBL and ring buffer length**:   |  |  |
        | --- | --- |
        | ```  bit ``` | ```  buffer length ``` |
        | 00B | 8K words |
        | 01B | 16K words |
        | 10B | 32K words |
        | 11B | 64K words |

**RBP[19:13](W) Ring Buffer (header) Pointer**: Specify the start address of the ring buffer. This specification is specified on 4Kword boundaries.
