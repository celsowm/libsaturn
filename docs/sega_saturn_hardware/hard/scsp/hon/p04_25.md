---

### ■PITCH register

**OCT[3:0](R/W) ; OCTave**: "OCT" is a register that has the function of raising or lowering the sound frequency by an octave for the waveform data stored in memory.

**FNS[9:0](R/W); Frequency Number Switch**: This register has a more detailed sounding frequency setting function between the upper and lower octaves of "OCT". If the "FNS" value and "OCT" value are both "0H", the pitch will match the sampling source. Figure 4.45 shows the relationship between the "FNS" and "OCT" values.
