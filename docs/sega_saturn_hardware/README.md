# Documentação baixada

Conteúdo gerado por `download_docs_md.py`.

## Recursos

- Converte páginas HTML para Markdown
- Baixa imagens para `_assets/`
- Reescreve links internos para navegação offline
- Gera `SUMMARY.md`

## Uso

```bash
pip install requests beautifulsoup4 markdownify
python download_docs_md.py
```
