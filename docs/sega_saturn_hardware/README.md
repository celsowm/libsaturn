# Sega Saturn hardware documentation

The [HTML manual collection](hard/index.md) is generated by
`scripts/download_docs_md.py`. The [additional primary manuals](manuals/README.md)
include the SH7604 Hardware Manual, SH-1/SH-2 Programming Manual, Saturn Dual CPU
User's Guide and VDP1 supplement, converted from pinned PDFs into Markdown.

See the [complete index](SUMMARY.md) for both collections and the
[PDF conversion instructions](manuals/README.md#reproduce) for reproducible
downloads, source hashes and page-coverage validation.

## Features

- Converts HTML pages to Markdown
- Downloads images to `_assets/`
- Rewrites internal links for offline navigation
- Generates `SUMMARY.md`

## Usage

```bash
pip install requests beautifulsoup4 markdownify
python scripts/download_docs_md.py
```
