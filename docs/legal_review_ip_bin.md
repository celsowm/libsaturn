# Revisao Legal - IP.BIN

Este MVP inclui `ip.bin` no fluxo padrao de build para acelerar testes locais.

Antes de release publica:

1. Validar origem e licenciamento do boot block usado em distribuicoes oficiais.
2. Confirmar politica de redistribuicao para marketplaces/repositorios publicos.
3. Registrar aprovacao legal junto aos artefatos de release.

Enquanto a revisao nao estiver concluida, prefira uso interno/experimental.
