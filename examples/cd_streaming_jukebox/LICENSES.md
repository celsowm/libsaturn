# Public-domain music provenance

`cd_streaming_jukebox` contains no downloaded recordings or samples. During
the build, `tools/generate_cd_streaming_jukebox_assets.py` synthesizes mono
PCM from small melody-note sequences written in this repository. The generated
PCM therefore has no third-party recording copyright.

The melodies are public-domain compositions:

- **Ode to Joy**, Ludwig van Beethoven, Symphony No. 9, Op. 125 (1824).
  The underlying work is public domain; an IMSLP score lists it accordingly:
  <https://imslp.org/wiki/Symphony_No.9%2C_Op.125_(Beethoven%2C_Ludwig_van)>.
- **Minuet in G major**, BWV Anh. 114, Christian Petzold (1677–1733), formerly
  attributed to J. S. Bach. The manuscript score is listed as public domain:
  <https://imslp.org/wiki/Minuet_(Pezold%2C_Christian)>.
- **Greensleeves**, traditional English melody, documented in William Ballet's
  lute book (c. 1590–1603). The manuscript source is listed as public domain:
  <https://imslp.org/wiki/William_Ballet%27s_lute_book%2C_IRL-Dtc_MS_408_(Ballet%2C_William)>.

Only the melody is used. The rhythm, monophonic arrangement, synthesis, PCM
encoding, and source code are original to this repository and fall under the
repository license.
